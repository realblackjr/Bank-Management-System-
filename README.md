# Bank Management System (Java)

This project is a console-based Bank Management System developed using Java and Object-Oriented Programming (OOP) concepts.

## Features
- Create Savings and Current Accounts
- Deposit Money
- Withdraw Money
- Transfer Funds
- View Account Details
- View Transaction History
- Global Transaction Log

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- VS Code
